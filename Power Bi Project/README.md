## Power BI
# 📊 DMART Sales Analytics Dashboard

## 📌 Overview

An interactive Power BI dashboard designed to analyze DMART sales performance and provide business insights through KPIs, charts, tables, and interactive slicers.

## 🛠️ Technology Used

- Power BI
- DAX
- Power Query

## 📈 Dashboard KPIs

- Total Sales
- Total Quantity
- Total Orders
- Total Customers
- Total Products Sold
- Average Order Value

## 📊 Dashboard Visuals

- Monthly Sales Trend
- Sales by Store
- Sales by Category
- Top 10 Products
- Sales Distribution by Payment Method

## 🎛️ Interactive Slicers

- Date
- Store
- Category
